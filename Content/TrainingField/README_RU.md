# Training Field – ассеты для Unreal Engine (PoC)

Готовый набор **облегчённых процедурных** 3D-ассетов для тренировочного поля. Содержит 7 отдельных Static Mesh моделей (3 куста, 3 дерева и 1 наблюдательная башня), два PBR-материала ландшафта и исходные текстуры растительности/башни. Подходит для быстрого прототипа уровня полёта дрона. **Это не фотограмметрия и не фотореалистичные сканы.**

Модели представлены в **Models/GLB/** (рекомендуемый вариант: **один меш на модель** с тремя слотами материалов, UV, встроенные PBR-материалы и изображения) и в **Models/OBJ/** (OBJ/MTL с ссылками на внешние файлы текстур). Объекты статичны, состоят из нескольких именованных групп материалов. Начальная точка каждого ассета — приблизительно на уровне земли, близко к центру основания.

**Текстуры:**
- `Textures/Ground_Grass/`: `BaseColor.png`, `Normal_DX.png`, `Roughness.png`, `AO.png` — 2048×2048, цветовая карта зелёного травяного покрытия.
- `Textures/Ground_Dirt/`: аналогичный набор для утоптанного грунта.
- `Textures/Foliage/`: маскированная листва, хвоя, кора дуба/берёзы/ели.
- `Textures/Tower/`: сталь, кровля и бетон.
- `Textures/Metallic_0.png`: чёрная карта при необходимости (для земли и растительности Metallic = 0).

Материалы ландшафта **не требуют отдельной меш-модели**: наносите их на Landscape / поверхность поля. Для отчётливых травинок рядом с камерой можно дополнительно добавить Geometry Grass / Landscape Grass Type — в этот архив отдельные травинки не входят.

## Импорт в Unreal Engine 5.x

1. Создайте директорию `Content/TrainingField` в проекте Unreal.
2. Импортируйте `.glb` из `Models/GLB/` через Content Browser (`Import`). Для некоторых версий UE понадобится включить **Interchange Framework** и соответствующий glTF/GLB importer. GLB удобен тем, что изображения материалов встроены.
3. Убедитесь, что размер соответствует таблице выше. Геометрия создана в метрах. glTF использует ось **Y вверх**; Unreal при корректном glTF-импорте переводит её в **Z вверх**. Для OBJ — исходная ось Z вверх, при импорте проверьте коэффициент перевода метров в сантиметры.
4. Если при импорте листва оказалась непрозрачной, настройте материал листьев: **Blend Mode = Masked**, **Two Sided = true**, RGB листовой текстуры в Base Color, A в Opacity Mask, **Metallic = 0**, **Roughness ≈ 0.9**. Для хвои настройка такая же.
5. Для деревьев/кустов используйте режим **Foliage** с типом **Static Mesh Foliage**, а не по отдельному Actor на каждый куст. Рандомизируйте Yaw 0–360° и Uniform Scale ~0.85–1.2.
6. Ландшафт: создайте материалы `M_Ground_Grass` и `M_Ground_Dirt`. Подключите карты в `Base Color`, `Normal`, `Roughness`, `Ambient Occlusion`. Для нормалей отключите sRGB; для Roughness/AO тоже отключите sRGB и установите подходящую маску/Compression Setting. Metallic = 0. Используйте WorldAlignedTexture или Landscape UV для тайлинга; при крупном поле масштабируйте примерно 2–4 м на повтор, ориентируясь на вид с дрона.
7. Для башни включите простую collision (например, Auto Convex/несколько простых коллайдеров). По умолчанию коллизии отдельных деталей в GLB не заготовлены. Экземпляры башни можно дублировать в уровне.

## Рекомендации для тренировочного поля

- Лесополоса: перемежайте дуб, берёзу и ель, делая 2–4 смещённых ряда. Соседние деревья слегка разворачивайте и масштабируйте. Не дублируйте одну модель без вариации.
- Кусты: используйте вдоль тропинок и на периферии, с небольшими группами из 2–5 кустов.
- Вблизи камеры отдельные листовые карточки будут выглядеть упрощённо: это **PoC-геометрия**, не production botanical scans.
- Для плотной лесополосы на MacBook Air и других устройствах: настройте Cull Distance и HLOD/LOD в Unreal; готовых геометрических LOD-цепочек **нет**.
- Растения статичны, wind-анимации нет. В UE можно позднее добавить World Position Offset в материалы.
- Модели и материал генерировались процедурно, внешние платные модели не использованы.

## Ограничения и проверка

Проверены: наличие 7 GLB-файлов и 7 OBJ-файлов, UV-координаты, конечность координат, встроенные материалы GLB (каждый GLB содержит 1 меш с 3 материалами), количество полигонов и карты нормалей/шероховатости земли 2K.

**Не проверены:** реальный импорт/рендер и производительность в Unreal Engine на вашей машине. Цвета и материалы могут потребовать ручной корректировки после импорта. Из-за процедурной генерации упрощены силуэты кустов/деревьев и микродеталь поверхности. Масштабирование PBR-карт до 2K выполнялось из процедурно рассчитанного 768px оригинала — это не фотоскан 2K.
